V-Server is up and running

This page replaces the default NGINX welcome screen. It is served from /var/www/v-server by a dedicated server block.

What is configured on this host

  • SSH public key authenticationThe public key was uploaded from the workstation that generated the key pair.
  • Password authentication disabledThe SSH daemon accepts key based logins only.
  • NGINX with a custom entry pointA separate site configuration replaces the packaged default site.
  • Git ready for GitHubUser name and email are set and a server side deploy key talks to GitHub over SSH.
